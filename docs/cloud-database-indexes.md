# 云数据库索引

## 饮食记录 `orders`

R-03 将饮食记录列表改为按 `orderTime`、`_id` 双字段游标分页，月历和本月回顾改为自然月范围查询。部署新版 `manageOrders` 前，请在微信云开发控制台为 `orders` 集合建立以下复合索引：

| 字段 | 排序 |
|---|---|
| `_openid` | 升序 |
| `orderTime` | 降序 |
| `_id` | 降序 |

该索引用于以下查询：

- 当前用户的饮食记录稳定倒序分页；
- 当前用户指定自然月范围内的记录查询；
- 相同 `orderTime` 下使用 `_id` 作为稳定游标，防止翻页重复或遗漏。

`summary` 使用 `_openid` 条件执行数据库计数和金额聚合。如果控制台提示缺少单字段索引，请另外为 `_openid` 建立升序索引。

索引创建完成并生效后再验证云函数；索引构建期间范围查询可能暂时返回缺少索引的数据库错误。
