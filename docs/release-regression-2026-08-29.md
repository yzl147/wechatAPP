## 1. 回归范围

本清单用于当前 `main` 分支的候选版本发布验收，覆盖 16 个注册页面、4 个云函数以及个人数据跨设备同步。重点检查小屏、全面屏安全区、大字体、长内容、断网和快速点击。

本轮代码侧基线：

- 微信基础库：`3.15.2`
- 自动检查：运行 `npm run check`
- 云函数：`manageDishes`、`manageCart`、`manageOrders`、`manageUserData`

## 4. 核心流程

### 4.1 首页与导航

- [ ] 冷启动进入首页，饮食清单和生活清单分别显示加载、成功或局部错误状态。
- [ ] 首页所有入口可进入对应页面，底部“首页 / 饮食清单 / 记录”切换正常。
- [ ] 页面返回后数据概览刷新，不出现重复跳转或异常留白。

### 4.2 菜谱与今日饮食清单

- [ ] 菜谱搜索、分类切换、收藏、详情和加入今日清单正常。
- [ ] 分类数量少时列表从顶部自然排列，不出现异常留白。
- [ ] 今日清单加减份数、删除单项、清空、采购缺口和保存记录正常。
- [x] 连续快速点击加减、加入和保存，只产生一次有效写入或按顺序更新。
- [ ] 菜品图片均从云存储加载，本地 `images/dishes` 未进入上传包。

### 4.3 库存与采购

- [ ] 新增库存、调整数量、设置/清除保质日期和删除食材正常。
- [ ] 删除时对象与不可恢复后果明确，删除中不能重复操作。
- [ ] 库存充足、部分不足和无库存时，采购缺口及状态文案正确。
- [ ] 过期、临期、正常和未设置日期均有文字状态，不只依赖颜色。

### 4.4 饮食记录

- [ ] 自己做、外出吃、点外卖三种记录均可保存并查看详情。
- [ ] 日历切月、选择日期、列表继续加载和本月回顾数据一致。
- [ ] 历史自己做记录可复用到今日清单。
- [ ] 单条删除可在详情撤销，单条和批量删除均进入“最近删除”。
- [ ] 从“最近删除”恢复后，记录重新出现在原日期和列表中。

### 4.5 生活清单

- [ ] 新建清单、使用默认/自定义模板、添加项目和勾选完成正常。
- [ ] 每日、每周和每月循环在下一轮正确重置。
- [ ] 删除项目和整张清单时提示明确，失败后原数据仍保留。
- [ ] 删除整张清单不影响已保存的历史完成记录。
- [ ] 记录页和本月回顾可打开生活完成详情。

### 4.6 今天吃什么

- [ ] 堂食、外卖、自己做可独立选择；未选择或空候选不会参与抽取。
- [ ] 两阶段抽取、再转一次、直接告诉我和最终确认正常。
- [x] 快速连续点击不会启动多次动画或产生多个结果。
- [ ] 候选新增、编辑、启停、删除和跨设备同步正常。

## 5. 异常与恢复

### 5.1 断网读取

- [x] 首页饮食和生活概览分别显示错误或缓存状态，不把失败伪装成 0 项。
- [x] 菜谱、今日清单、记录页显示错误态并提供重试。
- [x] 收藏、库存、采购状态、生活清单和候选页保留本地缓存，不被空数据覆盖。
- [x] 恢复网络后点击重试或重新进入页面可恢复正常。

### 5.2 断网写入

- [x] 收藏、库存、生活清单和候选写入失败时有明确提示，页面保留写入前数据。
- [x] 今日清单增删、保存记录、删除/恢复记录失败时可再次操作。
- [x] 失败提示不包含数据库堆栈、完整 OpenID 或其他内部异常。

### 5.3 快速点击

- [x] 保存、删除、恢复、创建清单和转盘动画期间按钮进入处理中状态。
- [x] 连续点击不会产生重复记录、重复清单或负库存。
- [x] 请求完成后按钮恢复可用，失败时不会永久锁定。

## 6. 长内容与边界数据

- [x] 菜名、地点、清单标题、项目和候选名称达到允许的最大长度时不横向溢出。
- [x] 菜谱包含较多食材和步骤时可滚动到页面底部。
- [x] 今日清单、库存、生活清单、饮食记录和最近删除超过一屏时最后一项不被底栏遮挡。
- [ ] 空列表、仅一项、恰好一页和多页数据均正常。
- [ ] 同一毫秒产生的多条记录或批量删除记录分页无重复、无遗漏。
