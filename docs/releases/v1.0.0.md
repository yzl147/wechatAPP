# v1.0.0 正式发布记录

“记事微清单” `v1.0.0` 已于 2026-09-02 正式发布为微信小程序。

## 发布基线

- 发布候选：`v1.0.0-rc3`
- 运行时代码基线：`10a2b36`
- 微信基础库：`3.15.2`
- 自动检查：123 项测试、16 个注册页面和 24 个打包排除项全部通过
- 人工验证：Android 真机、微信开发者工具 iPhone 模拟器、长内容、大字体、断网恢复和快速点击均通过
- 数据验证：菜谱、收藏、饮食记录、库存和生活清单保持完整，控制台无未处理异常
- 隐私接口：正式版本不调用剪贴板接口，也未引入定位、相机、相册、手机号等受限能力

## 主要功能

- 菜谱浏览、分类、收藏、详情和云存储图片
- 今日饮食清单、食材缺口、采购状态和库存管理
- 自己做、外出吃和点外卖三种饮食记录，以及历史复用和最近删除恢复
- 家务、出行、收纳和自定义生活清单，以及完成历史与本月回顾
- “今天吃什么”两阶段转盘和跨设备同步的候选餐单

## 发布后策略

- 首周优先观察云函数错误、数据库异常、同步失败和资源用量，不立即叠加大型功能。
- 紧急缺陷使用 `v1.0.x` 修复版本；向后兼容的新功能使用 `v1.1.0`。
- 后续候选方向为库存优先推荐、转盘决策历史和经用户确认的库存扣减，每轮只选择一个独立任务。
