# 餐饮点餐小程序

一个简单的微信小程序，用于菜单浏览、购物车管理和订单处理。

## 功能

- **菜单浏览**：查看菜品列表，支持分类筛选
- **购物车**：将菜品加入购物车，修改数量
- **下单**：提交订单，选择配送地址
- **订单管理**：查看订单历史，了解订单状态

## 技术栈

- 微信小程序原生框架
- 本地存储（Storage）
- 云开发（可选）

## 页面

| 页面 | 说明 |
|-----|------|
| 首页 | 菜品菜单列表 |
| 详情页 | 菜品详细信息 |
| 购物车 | 已选菜品列表 |
| 订单列表 | 历史订单 |
| 订单详情 | 单个订单详情 |
